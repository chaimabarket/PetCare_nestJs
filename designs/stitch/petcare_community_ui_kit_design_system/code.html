Anatomie & Règles de composition

La carte d'adoption constitue l'unité d'information centrale de l'application. Elle est conçue pour concilier rigueur vétérinaire et déclenchement émotionnel responsable.

1. Format de surface

Coins de 16px (rounded-2xl), fond blanc pur (#FFFFFF), padding interne modulaire de 16px.

2. Photographie 4:3

Ratio calibré 4:3 avec zoom subtil (+5%) au hover pour humaniser l'animal sans déformation.

3. Badge & Favori superposés

Flottants avec effet dépoli (backdrop-blur) pour garantir un contraste optimal sur toute image.

4. Étiquettes d'affinité

Mise en avant immédiate des critères de compatibilité (foyer, enfants, autres espèces).

Tokens: surface-container-lowest + rounded-2xl + shadow-sm PetCare UI Core
